# 영어 지문 분석본 자동 생성기

영어 지문을 붙여넣으면 AI(Google Gemini)가 **청크 단위 직독직해 분석본**을 자동으로 만들어
좌우 7:3 카드 형식(왼쪽 영문+한글 / 오른쪽 어법·어휘 해설)으로 보여 주는 웹앱입니다.
문장별 해석·구문·어법·어휘, 주제·흐름 요약표, 핵심 어휘표를 생성하며, 인쇄/PDF 저장을 지원합니다.

- **백엔드**: 거의 Python 표준 라이브러리 (pip 의존성은 `requirements.txt`의 두 개 —
  로그인·저장용 `google-cloud-firestore`, PDF에서 지문 꺼내기용 `pdfminer.six`)
- **AI**: Google Gemini API (`gemini-3.7-flash`, 일부 기능만 `gemini-3.1-pro-preview`)
- **프런트엔드**: 정적 HTML/CSS/JS (`public/`)

## 1. 준비물

- Python 3 (이미 설치되어 있음)
- 관리자(운영자) 본인의 Gemini API 키 — https://aistudio.google.com/app/apikey 에서 무료 발급
  (사용자 개개인은 키가 필요 없습니다 — 아래 "로그인" 참고)

## 2. 실행 & 관리자 키 설정

```bash
python server.py
```

또는 Windows에서 `run.bat` 더블클릭. 그런 다음 브라우저에서 **http://localhost:8000** 접속.

관리자 키는 화면이 아니라 **환경변수로만** 설정합니다 (모든 로그인 사용자가 이 키
하나를 같이 씁니다):

```powershell
setx GEMINI_API_KEY "AIza..."
```

(새 창에서 서버 재실행 시 적용.) 이 값이 없으면 AI 관련 기능이 전부 막힙니다.

## 3. 사용법

1. (처음 한 번) **로그인**하거나 **회원가입**합니다 — 개인 API 키 입력 불필요.
2. 영어 지문을 입력창에 붙여넣습니다.
   - **📷 사진에서 가져오기** — 사진 1장 = 지문 1개로 옮겨 적습니다(AI가 읽습니다).
   - **📄 PDF에서 가져오기** — 교과서 본문·모의고사 PDF를 통째로 올리면 **문단(또는
     문항)마다 지문 1개**로 나눠 입력칸을 한 번에 채웁니다. PDF 안의 글자를 그대로
     꺼내므로 요금이 들지 않고 오타도 생기지 않습니다(문항형 자료에서는 문항 번호가
     지문 이름으로 붙습니다). 글자가 없는 스캔본 PDF는 사진으로 저장해 위 📷 쪽으로
     올려 주세요.
3. (선택) **목표 어법**에 특히 강조할 문법을 적습니다. 예: `분사구문, 관계대명사`.
4. **용도**를 교사용/학생용 중 선택합니다.
5. **분석하기** (또는 Ctrl+Enter) → 20~60초 후 분석본이 생성됩니다.
6. **🖨️ 인쇄 / PDF** 버튼으로 출력하거나 PDF로 저장합니다.

## 4. 로그인 (구글 OAuth + 이메일/비밀번호 회원가입)

사용자는 개인 Gemini 키를 입력하지 않고, 로그인만 하면 AI 기능을 쓸 수 있습니다 —
실제 AI 호출은 전부 위 2번의 **관리자 키 하나**로 이루어지고, 로그인은 "누가 그
키를 쓰는지" 구분하는 용도입니다. 로그인 방법은 두 가지를 함께 제공합니다:

- **구글 로그인**: 팝업으로 구글 계정 인증.
- **이메일/비밀번호 회원가입**: 이메일로 6자리 인증코드를 받아 확인한 뒤 계정이 만들어집니다.

### 계정별 잔액(원) — 정찰 요금제

누구나 로그인만 하면 관리자 키를 같이 쓰므로, 사용량이 한 사람에게 쏠리거나 계정이
늘어날수록 과금이 눈덩이처럼 불어나는 걸 막기 위해 **계정마다 원(KRW) 잔액**을 둡니다.
Gemini 실사용량을 그때그때 재는 대신, **행동 하나당 고정 가격**을 매기는 정찰제입니다 —
사용자 입장에서 예측 가능하고, 관리자 입장에서도 "이 버튼 한 번 = 얼마"가 분명합니다.
실제 Gemini 비용과의 차액(마진 또는 손실)은 관리자가 흡수합니다.

- 계정을 새로 만들면(구글 로그인 최초 1회, 또는 이메일 인증 완료) `DEFAULT_USER_KRW`
  (기본 3,000원) 만큼 잔액이 지급됩니다.
- 기능별 가격(전부 환경변수로 조정 가능):

  | 기능 | 가격 | 단위 |
  |---|---:|---|
  | 지문 분석 | `PRICE_ANALYZE_KRW` (기본 300원) | 지문 1개당 |
  | 객관식 · 지문유지형 (주제·제목·요지·내용일치 등) | `PRICE_MCQ_PLAIN_KRW` (기본 250원) | (지문×유형) 1개당 |
  | 객관식 · 지문변형형 (빈칸·어법·순서·문장삽입 등) | `PRICE_MCQ_TRANSFORM_KRW` (기본 250원) | (지문×유형) 1개당 |
  | 주관식 (전 유형 동일가) | `PRICE_SAQ_KRW` (기본 250원) | (지문×유형) 1개당 |
  | └ 같은 유형의 2문항째부터 | `PRICE_EXTRA_QUESTION_KRW` (기본 100원) | 추가 문항 1개당 |
  | 워크북 | `PRICE_WORKBOOK_STAGE_KRW` (기본 100원) | 지문 1개당, 고른 단계 1개마다. 8단계를 다 고르면 `PRICE_WORKBOOK_MAX_KRW`(기본 700원)에서 멈춘다 |
  | 지문 변형(문제 생성 전 재작성) | `PRICE_REWORD_KRW` (기본 0원, 미정) | 호출 1회당 |
  | 사진에서 지문 옮기기(OCR) | `PRICE_OCR_KRW` (기본 0원, 미정) | 사진 1장당 |
  | PDF에서 지문 꺼내기 | `PRICE_PDFSPLIT_KRW` (기본 0원, 미정) | 규칙으로 나눌 때는 **언제나 0원**(AI를 부르지 않음). 규칙이 실패해 'AI로 다시 시도'를 눌렀을 때만 파일 1개당 |
  | 단어장 · 사진에서 단어 목록 인식 | `PRICE_VOCAB_OCR_KRW` (기본 0원, 미정) | 사진 1장당 |
  | 단어장 · PDF에서 단어 목록 정리 | `PRICE_VOCAB_PDF_KRW` (기본 0원, 미정) | 규칙으로 뽑힐 때는 **언제나 0원**. 규칙이 실패해 'AI로 다시 시도'를 눌렀을 때만 파일 1개당 |

- **유형별 문항 수**: 출제 유형 칸의 각 유형 옆 `−` `+` 로 몇 문항을 뽑을지 정합니다.
  가격은 `유형 단가 + 추가문항 × 100원` — 예를 들어 객관식에서 주제 2문항·제목 1문항·
  요지 3문항이면 `350 + 250 + 450 = 1,050원`입니다(지문 1개·변형 1세트 기준).
  한 호출에서 지문과 프롬프트는 문항 수와 무관하게 한 번만 입력되므로, 2문항째부터는
  출력 비용만 들어 더 싸게 매깁니다.
- 유형마다 **최대 문항 수가 다릅니다**(`QUIZ_TYPE_MAX`). 주제·제목·요지·내용일치 5,
  빈칸·어휘 6, 어법 4, 순서·문장삽입 2, OX진위 8, 조건 영작·문장 전환 3 … —
  지문 재사용 유형은 문항이 늘어도
  출력이 거의 안 커져 넉넉하고, 순서·문장삽입은 지문의 문장 수에 물리적으로 묶여
  있으며, 어법 계열은 지문에 실재하는 문법 포인트 수를 넘기면 정답 시비가 납니다.
  값은 `server.py`와 `public/app.js` 두 곳에 같은 표로 있으니 **함께** 고쳐야 합니다.
- 한 번의 '문제 만들기'는 **총 200문항**까지입니다(지문 수 × 변형 세트 수 × 문항 수).
  넘기면 만들 문항 수·AI 호출 횟수·예상 요금을 보여 주는 창이 떠서,
  **'나눠서 진행'(200문항씩 묶어 차례로) / '그대로 진행' / '취소'** 중에 고릅니다 —
  거부하지 않습니다. 나눠도 요금 총액은 같습니다.

- **모델도 사용자가 고르지 않고 기능마다 서버가 고정합니다** (화면에 모델 선택
  칸이 없음). 문제 제작은 **지문을 고쳐 만드는 유형이 하나라도 섞이면** 그 호출을
  `GEMINI_MODEL_PRO`(Pro)로 보냅니다 — 객관식이든 주관식이든 마찬가지입니다.
  지문을 그대로 싣는 유형(주제·제목·요지·내용일치·영영풀이·OX진위)만 골랐을 때만
  `GEMINI_MODEL`(Flash)로 갑니다. 지문변형 '단어 5개 이상 변형'도 Pro입니다.
  심어 놓은 오류가 진짜 오류인지 서버가 기계로 검사할 수 없어(분석본과 달리 첫 출력이
  곧 최종본이다) 모델 정확도에 기대는 자리이기 때문입니다.
  나머지(지문 분석·워크북·OCR·지문변형 light)는 전부 Flash입니다.
- 요청 전에 잔액을 먼저 확인합니다 — **부족하면 아예 Gemini를 부르지 않고** 바로
  "잔액이 부족합니다" 오류를 냅니다. 생성이 **성공했을 때만** 차감하므로, 실패한
  시도는 요금이 나가지 않습니다.
- 특정 사용자에게 더 주고 싶으면 아래 **관리자 페이지**에서 충전하거나, Firestore
  콘솔 → `users` 컬렉션 → 그 사용자 문서 → `krw_remaining` 값을 직접 고치면 됩니다.

### 관리자 페이지 (`/admin.html`)

회원 목록과 각자 잔액을 보고, 잔액을 임의로 충전(또는 회수)할 수 있는 별도
페이지입니다. 메인 화면 어디에도 링크가 없고 주소를 직접 입력해야 들어갈 수
있습니다 — 하지만 링크가 없다고 보안이 되는 건 아니므로, 실제 접근 제어는 아래
아이디·비밀번호 로그인이 담당합니다.

- 켜려면 `ADMIN_USERNAME`(기본 `admin`)과 **`ADMIN_PASSWORD`를 반드시 설정**하세요.
  `ADMIN_PASSWORD`가 없으면 관리자 로그인은 항상 거부됩니다.
- 일반 회원 로그인과 완전히 분리된 별도 로그인이며(이메일 형식 검증 없음), 세션은
  12시간 뒤 만료됩니다.
- 같은 IP에서 5회 연속 틀리면 5분간 잠깁니다(짧은 비밀번호를 무차별대입으로 뚫는 것 방지).
  **그래도 비밀번호는 충분히 길고 무작위로 정하세요** — 뚫리면 전체 회원 이메일이
  노출되고 잔액(=관리자 키 실사용량)을 누구나 조작할 수 있습니다.

로그인하면 두 가지를 저장해 둘 수 있습니다.

1. **지문만** — 지문 입력칸 아래 **💾 지문 저장** 버튼. 아직 아무것도 만들지 않았어도
   타이핑(또는 사진에서 가져오기)해 둔 지문을 그대로 넣어 둘 수 있고, 나중에 불러와
   원하는 탭을 돌리면 됩니다.
2. **제작 자료** — 각 탭의 **💾 저장** 버튼. 만든 분석본·문제·워크북·단어장을 그때 쓴
   지문·설정과 함께 저장해, 불러와서 재인쇄하거나 이어서 수정할 수 있습니다.

저장함도 둘로 나뉘어 있어(상단 **📄 지문 저장함** / **📦 제작 자료 저장함**) 찾으려는
쪽만 바로 열립니다. 저장은 버튼을 직접 눌렀을 때만 이루어지고(자동 저장 아님),
계정별로 분리되어 다른 사람 자료는 보이지 않습니다.

이 기능을 켜려면 아래 값들을 환경변수로 설정해야 합니다. **`GOOGLE_APPLICATION_CREDENTIALS_JSON`
(Firestore)이 없으면 로그인 자체가 안 되고, 이제 로그인이 AI 기능의 전제 조건이므로
분석·문제 제작·워크북 등 전체가 함께 막힙니다** — 반드시 설정하세요:

1. **`GOOGLE_APPLICATION_CREDENTIALS_JSON`** (필수) — [Google Cloud Console](https://console.cloud.google.com)에서
   프로젝트를 만들고 Firestore를 Native 모드로 활성화한 뒤, IAM → 서비스 계정에서
   "Cloud Datastore User" 권한을 가진 서비스 계정을 만들고 JSON 키를 발급받습니다.
   그 JSON 파일의 **내용 전체**를 이 환경변수 값으로 넣습니다(비밀값 — 절대 커밋하지
   마세요). 로컬 개발 중에는 대신 표준 변수 `GOOGLE_APPLICATION_CREDENTIALS`에 JSON
   파일 경로를 넣어도 됩니다.
2. **`GOOGLE_CLIENT_ID`** (선택, 구글 로그인용) — 같은 프로젝트의 "사용자 인증 정보 →
   OAuth 클라이언트 ID 만들기"(웹 애플리케이션)로 발급받습니다. "승인된 자바스크립트
   원본"에 `http://localhost:8000`과 실제 배포 주소를 등록하세요. 비밀값이 아니라
   화면(로그인 버튼)에 그대로 노출됩니다. 없으면 구글 로그인 버튼만 비활성화되고
   이메일/비밀번호 회원가입은 그대로 동작합니다.
3. **`SMTP_USER` / `SMTP_PASSWORD`** (선택, 이메일 회원가입용) — 인증코드를 보낼 Gmail
   계정과 [앱 비밀번호](https://myaccount.google.com/apppasswords)(2단계 인증 필요).
   없으면 이메일이 발송되지 않고, 대신 인증코드가 **서버 로그**에 출력됩니다 — 관리자가
   로그를 보고 사용자에게 직접 전달할 수 있습니다(개발·소규모 운영용 임시방편).

저장 데이터·계정 정보는 서버 파일이 아니라 Firestore(구글의 영구 저장소)에 들어가므로,
재배포하거나 서버가 재시작돼도 사라지지 않습니다.

## 설정 (환경변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | (필수) | 관리자의 Gemini API 키. 없으면 AI 기능 전체가 막힘 |
| `PORT` | `8000` | 서버 포트 |
| `HOST` | `0.0.0.0` | 바인딩 주소 |
| `GEMINI_MODEL` | `gemini-3.7-flash` | 기본(Flash) 모델 — 지문 분석·워크북·OCR·지문변형(light), 그리고 지문을 그대로 싣는 유형만 고른 문제 제작에 씀 |
| `GEMINI_MODEL_PRO` | `gemini-3.1-pro-preview` | 정확도가 더 필요한 작업 전용 모델 — 지문을 고쳐 만드는 유형이 섞인 문제 제작(객관식·주관식 모두)과 지문변형(heavy)에 씀 |

## 배포 메모

로컬 실행용으로 만들었지만, 같은 구조로 사내/외부 서버에도 올릴 수 있습니다.
외부에 공개할 경우 API 키 보호를 위해 반드시 서버 측 환경변수로만 키를 두고,
필요하면 접근 제어(인증)를 추가하세요.
