# 영어 지문 분석본 자동 생성기

영어 지문을 붙여넣으면 AI(Google Gemini)가 **청크 단위 직독직해 분석본**을 자동으로 만들어
좌우 7:3 카드 형식(왼쪽 영문+한글 / 오른쪽 어법·어휘 해설)으로 보여 주는 웹앱입니다.
문장별 해석·구문·어법·어휘, 주제·흐름 요약표, 핵심 어휘표를 생성하며, 인쇄/PDF 저장을 지원합니다.

- **백엔드**: Python 표준 라이브러리만 사용 (pip 설치 불필요)
- **AI**: Google Gemini API (`gemini-2.5-flash`)
- **프런트엔드**: 정적 HTML/CSS/JS (`public/`)

## 1. 준비물

- Python 3 (이미 설치되어 있음)
- Gemini API 키 — https://aistudio.google.com/app/apikey 에서 무료 발급

## 2. 실행 & 키 입력

```bash
python server.py
```

또는 Windows에서 `run.bat` 더블클릭. 그런 다음 브라우저에서 **http://localhost:8000** 접속.

키 입력 방법은 두 가지 — 둘 중 하나만 하면 됩니다:

- **(권장) 화면에서 입력**: 상단 **‘Gemini API 키’** 칸에 키를 붙여넣습니다.
  키는 **이 브라우저(localStorage)에만** 저장되고, 다음에 열 때 자동으로 채워집니다.
  서버 파일이나 코드에는 저장되지 않습니다.
- **환경변수로 설정**(여러 사람이 공용으로 쓸 때 등):
  ```powershell
  setx GEMINI_API_KEY "AIza..."
  ```
  (새 창에서 서버 재실행 시 적용. 이 경우 화면 키 칸은 비워 두면 됩니다.)

## 3. 사용법

1. (처음 한 번) Gemini API 키를 입력합니다.
2. 영어 지문을 입력창에 붙여넣습니다.
3. (선택) **목표 어법**에 특히 강조할 문법을 적습니다. 예: `분사구문, 관계대명사`.
4. **용도**를 교사용/학생용 중 선택합니다.
5. **분석하기** (또는 Ctrl+Enter) → 20~60초 후 분석본이 생성됩니다.
6. **🖨️ 인쇄 / PDF** 버튼으로 출력하거나 PDF로 저장합니다.

## 설정 (환경변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | (선택) | Gemini API 키. 화면에서 입력하면 없어도 됨 |
| `PORT` | `8000` | 서버 포트 |
| `HOST` | `0.0.0.0` | 바인딩 주소 |
| `GEMINI_MODEL` | `gemini-3.6-flash` | 사용할 모델 |
| `GEMINI_TIMEOUT` | `300` | Gemini 호출 1회의 소켓 타임아웃(초) |
| `MAX_RETRY_TOTAL` | `150` | 누적 재시도 대기 상한(초). 넘으면 한국어 오류로 안내 |
| `REFINE_BUDGET` | `86400` | 이 시간(초)을 쓴 뒤에는 품질 보정 재요청을 시작하지 않음 |

> 위 세 값은 **요청 시간 예산**입니다. 로컬은 요청을 끊는 프록시가 없으므로
> 기본값을 넉넉히 두어, Gemini가 503(과부하)을 내도 오래 기다려 결국 성공시킵니다.
>
> 반면 Render 등 배포 환경의 프록시는 응답 없는 요청을 100초 안팎에서 끊고
> JSON 대신 HTML 에러 페이지를 반환합니다. 그래서 **배포 환경에서만** 값을 줄이며,
> 그 설정은 `render.yaml`의 `envVars`에 들어 있습니다. 로컬에서는 신경 쓰지 않아도 됩니다.

## 배포 메모

로컬 실행용으로 만들었지만, 같은 구조로 사내/외부 서버에도 올릴 수 있습니다.
외부에 공개할 경우 API 키 보호를 위해 반드시 서버 측 환경변수로만 키를 두고,
필요하면 접근 제어(인증)를 추가하세요.

## 참고

- 문장 카드의 영문·해설 마크업은 AI가 생성해 브라우저에서 렌더링됩니다(로컬 교사 도구 기준).
  외부 공개 서비스로 확장한다면 출력 HTML 검증(sanitize)을 추가하는 것을 권장합니다.
